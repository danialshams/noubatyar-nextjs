# نوبت‌یار — Next.js 16 / Prisma 7 / PostgreSQL

سامانه مستقل مدیریت رزرو چندکسب‌وکاری با رابط کاربری فارسی/RTL، تقویم شمسی (نمایش)، صفحه رزرو عمومی پنج‌مرحله‌ای، مدیریت مشتریان، متخصصان، شعب، خدمات، لیست انتظار، بسته‌ها، تخفیف، گزارش‌ها و اعلان‌های داخلی.

**پشته:** Next.js 16 App Router, React 19, TypeScript, Prisma 7, PostgreSQL, Zod و محاسبات مستقل منطقه زمانی با Intl. هیچ وابستگی به FastAPI یا Lovable در کد عملیاتی وجود ندارد.

## راه‌اندازی

1. Node.js 22.18+ و PostgreSQL 15+ نیاز است.
2. فایل `.env.example` را در `.env` کپی و `DATABASE_URL` و یک `SESSION_SECRET` تصادفی بلند تنظیم کنید (حداقل ۳۲ کاراکتر).
3. `npm install`
4. `npx prisma generate`
5. `npx prisma db push` (ایجاد اسکیمای اولیه در دیتابیس خالی)
6. `npm run db:constraints` (اعمال قیدها و تریگرهای ضدتداخل روی PostgreSQL؛ اجباری)
7. برای داده‌های نمایشی فقط در محیط توسعه ابتدا `DEMO_SEED=true` و سپس `npm run db:seed`؛ روی production اجرا نشود.
8. `npm run dev` و سپس `http://localhost:3000`
9. پیش از انتشار: `npm run lint && npm run test:core && npm test && npm run build`. تست‌های تراکنشی دیتابیس را **فقط روی دیتابیس جداگانه** با `CI_INTEGRATION=true npm run test:db` اجرا کنید.
10. برای استفاده از CI و استقرار خودکار GitHub لازم است مخزن مستقل ساخته و سورس در آن قرار داده شود. CI داخل `.github/workflows/ci.yml` موجود است.
11. فایل lock در این بسته موجود نیست زیرا ثبت وابستگی‌ها در محیط حاضر به‌دلیل قطع دسترسی npm ممکن نبود. پس از `npm install`، فایل `package-lock.json` را به مخزن اضافه و در مرحله بعد CI را به `npm ci` تغییر دهید.

> **مهم:** قیدهای PostgreSQL فایل `extra-constraints.sql` را حذف نکنید. منطق API نیز با `pg_advisory_xact_lock` و Transaction سریال‌شونده از ثبت نوبت هم‌زمان جلوگیری می‌کند. نبودن قیدها ایمنی نهایی دیتابیس را کاهش می‌دهد.

## ساختار و امنیت

- همه درخواست‌های مدیریتی ابتدا نشست امضاشده HMAC و عضویت و نقش کاربر در سازمان را روی سرور بررسی می‌کنند.
- داده‌ها توسط فیلتر `orgId` در API و اعتبارسنجی ارجاعات بین جداول ایزوله می‌شوند. **RLS در سطح دیتابیس جداگانه هنوز پیاده‌سازی نشده است**؛ حساب دیتابیس باید صرفاً در سرور استفاده شود.
- کوکی نشست `HttpOnly`، `SameSite=Lax` و در production با `Secure` است؛ فرایندهای نوشتنی مبدأ درخواست را بررسی می‌کنند.
- اطلاعات رزرو عمومی فقط از طریق اندپوینت محدود و بدون افشای اطلاعات مشتریان قابل دسترسی‌اند؛ نرخ درخواست‌ها محدود شده است.
- زمان در دیتابیس UTC و در برنامه بر اساس timezone کسب‌وکار محاسبه می‌شود. تاریخ شمسی برای نمایش است، تاریخ داده‌ها میلادی ISO ذخیره می‌شود.
- پرداخت آنلاین، پیامک و ایمیل تا زمان اتصال واقعی سرویس‌دهنده اجرا نمی‌شوند؛ تنها پرداخت‌های حضوری/کارت‌خوان/انتقال بانکی با ثبت دستی `paid` هستند.
- خروجی CSV برای داده‌های مدیریتی مجاز ارائه شده؛ در مجموعه‌های پرحجم باید pagination سمت سرور افزوده شود.

## انتقال به Vercel و هاست شخصی

پروژه یک Node.js استاندارد با Next.js App Router است. در Vercel: repository را Import، محیط production را با `DATABASE_URL` ، `DIRECT_URL` (اتصال مستقیم برای عملیات دیتابیس) و `SESSION_SECRET` تنظیم، درگاه دیتابیس PostgreSQL شبکه‌ای و TLS برقرار و build را اجرا کنید. برای هاست اختصاصی: `npm install && npx prisma generate && npm run db:constraints && npm run build && npm run start` (پس از تولید package-lock، از `npm ci` استفاده کنید) با reverse proxy HTTPS و PostgreSQL. فایل‌های تولیدی در filesystem محلی نگهداری نشده‌اند.

برای انتقال دیتابیس PostgreSQL از `pg_dump --format=custom` و `pg_restore --clean --if-exists` با تأیید نسخه PostgreSQL استفاده کنید. هنگام انتقال، برنامه را در حالت نگهداری بگذارید، از داده‌ها backup بگیرید، آدرس دیتابیس جدید را تنظیم و تست رزرو/حذف/لغو را انجام دهید.

## محدودیت‌های فعلی و کارهای پیش از بهره‌برداری جدی

- **تأیید عملیاتی هنوز انجام نشده است**: `npm install` در محیط تهیه بسته به‌خاطر خطای دسترسی به registry.npmjs.org تکمیل نشد؛ به همین دلیل `next build`، تولید Prisma و تست یکپارچه PostgreSQL اینجا قابل اجرا نبود. ۱۱ آزمون مستقل موتور زمان‌بندی با Node و بررسی نحوی ۴۵ فایل TS/TSX موفق بودند، اما معادل تست اجرا روی وب‌سرور نیستند. به `QA_REPORT.md` مراجعه کنید.
- راه‌اندازی OTP/SMS، درگاه آنلاین و ارسال ایمیل نیاز به کلید API سرویس‌دهنده دارد.
- ایجاد نوبت تکرارشونده روزانه/هفتگی (با گزارش تداخل)، دعوت یک‌بارمصرف عضو تیم، ثبت نوبت دستی و Cron اعلان داخل پنل کدنویسی شده‌اند ولی بدون اجرای یکپارچه روی دیتابیس واقعی هنوز تأیید عملیاتی ندارند. رزرو چندمنبعی پیچیده و تخصیص چند متخصص مستقل به خدمات یک رزرو به‌صورت عمومی پیاده‌سازی نشده‌اند.
- در سطح شرکتی، مدیریت کلیدها، لاگ امن، کنترل abuse و آزمون concurrent load باید بازبینی شود.

## قابلیت‌های توسعه‌یافته در این بسته

- چندخدمتی با شناسه مشترک رزرو و لغو/جابه‌جایی گروهی در یک تراکنش؛ انتخاب متخصص واحد واجد شرایط برای کل رزرو
- نوبت دستی مدیر، رزروهای تکرارشونده تا ۱۲ رخداد، نمایش شمسی تعاملی، ظرفیت گروهی و کنترل تداخل اتاق‌ها
- دعوت مدیر و متخصص با توکن هش‌شده و انقضای ۷ روزه و محدودسازی دسترسی متخصص
- ثبت پرداخت حضوری با بررسی مانده تحت قفل تراکنشی؛ پرداخت آنلاین بدون درگاه فعال نیست
- بسته‌های خدمت، مصرف جلسه، مانده اعتبار مشتری، سوابق تغییرات، CSV و اعلان داخل پنل
- Cron ساعتی از طریق `vercel.json` یا زمان‌بند خارجی با `CRON_SECRET`، با حفظ وضعیت «نیازمند اتصال سرویس» برای SMS و ایمیل

**این سورس به معنای نرم‌افزار عملیاتی تست‌شده یا استقرار موفق نیست.** برای راه‌اندازی عمومی، موارد `QA_REPORT.md` باید روی یک محیط شبکه‌دار و پایگاه‌داده آزمایشی مستقل تأیید شوند.


## حالت پیش‌نمایش عمومی بدون ورود (Public Showcase)

برای نمایش عمومی نمونه بدون دیتابیس یا ورود، مقدار `PUBLIC_DEMO_MODE=true` را در متغیرهای محیطی Vercel/لوکال تنظیم کنید. صفحه `/` لینک مستقیم پنل `/app/dashboard` و رزرو نمونه `/book/demo-rose-salon` را نمایش می‌دهد. داده‌ها توسط `src/lib/public-demo.ts` به‌صورت ساختگی و قطعی تولید می‌شوند و به هیچ اطلاعات واقعی متصل نیستند. این مجموعه شامل حدود ۱۱۵۲ نوبت، ۲۴۰ مشتری، ۱۶ متخصص، ۲۴ خدمت، ۴ شعبه و داده‌های فراوان برای بخش‌های جانبی است. تمامی APIهای نمایش داده‌های نمونه فقط GET هستند؛ ایجاد/ویرایش/حذف، رزرو واقعی، تغییر وضعیت، پرداخت و ارسال پیامک باید غیرفعال باقی بمانند.

**هشدار:** حالت نمایش عمومی برای استفاده عملیاتی نیست. برای راه‌اندازی مشتری واقعی، `PUBLIC_DEMO_MODE=false`، `DATABASE_URL`، `DIRECT_URL` و `SESSION_SECRET` معتبر تنظیم کنید؛ migrations، constraints و تست‌ها را اجرا کرده و فقط سپس سرویس عمومی را فعال کنید. اطلاعات تست هرگز با پایگاه داده مشتری واقعی ادغام نشوند.
